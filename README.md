# Care Companion – AI-Assisted Coding Workshop (CSUEB)

This repository contains a caregiver-support demo application built during the AI-assisted coding workshop.

This app is non-diagnostic and educational.

## What This App Demonstrates

- Risk signal extraction from narrative notes
- Structured action planning
- Clinician-ready summaries
- Care coordination messaging
- Caregiver wellbeing support

---

## Run Locally

Mac/Linux:
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py

Windows PowerShell:
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run app.py
